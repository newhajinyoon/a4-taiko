## 소개

이 프로젝트는 카메라를 통해 나무젓가락의 움직임을 실시간으로 인식하여, 특정 영역(= hit zone)에 들어가면 해당 키(D, F, J, K)를 자동으로 눌러주는 시스템입니다.  
게임 중에 손쉬운 컨트롤 입력이 가능하도록 설계되었으며, DIY 방식으로 누구나 쉽게 제작해 볼 수 있습니다.

## 필요 준비물

- **나무젓가락** (혹은 인식 가능한 막대기)
- **웹캠/USB 카메라**
- **컴퓨터**
- **(선택)** A4 용지: 배경이나 가이드라인 설정에 활용 가능

## 사용 기술 및 라이브러리

- **Python 3.x**
- **OpenCV** (`cv2`)
- **NumPy**
- **PyAutoGUI**

## 사용 방법

1. **프로그램 실행**  
   터미널에서 아래와 같이 실행합니다.
   ```bash
   python taegodalin_controller.py
   ```
   실행 시 카메라 영상을 실시간으로 확인할 수 있는 창이 뜹니다.

2. **Hit Zone 확인 및 설정**  
   - 기본적으로 hit zone은 **D, F, J, K** 키에 매핑되어 있으며, 영상 상에 빨간 점과 텍스트로 표시됩니다.
   - 만약 hit zone의 좌표를 재설정하고 싶다면, **D, F, J, K** 키를 눌러 해당 좌표를 새롭게 지정할 수 있습니다.
     - 키를 누르면 “설정할 키 ○의 좌표를 클릭하세요.”라는 메시지가 출력되고, ROI 선택 창이 나타납니다.
     - 마우스로 원하는 영역을 드래그하여 선택한 후 Enter 키를 누르면 해당 영역의 좌측 상단 좌표가 hit zone으로 설정됩니다.
   - **꼭 화면에 드럼이 꽉 찰 정도로 해주세요. 나무젓가락을 들었을때 나무젓가락의 초록색 부분이 화면 밖으로 나가야합니다.**
3. **키 입력 모드 전환**  
   - 기본 상태에서는 키 입력 모드가 **비활성화** 되어 있습니다.
   - **Q** 키를 눌러 키 입력 모드를 **활성화/비활성화** 할 수 있습니다.
     - 활성화되면 카메라에 인식된 나무젓가락의 위치에 따라 자동으로 해당 키(예: D, F, J, K)가 눌리거나 해제됩니다.
  
4. **줌 및 화면 오프셋(offset) 조절**  
   - **P**: 줌 인
   - **O**: 줌 아웃
   - **S**: 화면 offset - 위로 이동
   - **X**: 화면 offset - 아래로 이동
   - **Z**: 화면 offset - 왼쪽으로 이동
   - **C**: 화면 offset - 오른쪽으로 이동

5. **프로그램 종료**  
   - 현재 코드는 ESC 키(혹은 창 종료)를 이용해 프로그램을 종료할 수 있도록 구성되어 있습니다.  
   - 종료 전 활성화된 모든 키 입력은 자동으로 해제됩니다.

## 동작 원리

- **영상 처리**:  
  카메라로부터 받은 영상을 OpenCV를 이용해 HSV 색상 공간으로 변환한 뒤, 미리 정의된 초록색 범위에 해당하는 영역을 검출합니다. (초록색 범위는 필요에 따라 조정 가능합니다.)

- **객체 인식**:  
  마스크 처리를 통해 검출된 컨투어를 분석하여 나무젓가락의 위치와 중심 좌표를 계산합니다.

- **Hit Zone 감지**:  
  계산된 중심 좌표가 설정된 hit zone 내에 있는지 판단하고, 해당 키(D, F, J, K)가 감지되면 PyAutoGUI를 통해 해당 키 입력을 에뮬레이션합니다.

- **동시 입력 지원**:  
  여러 hit zone이 동시에 감지될 경우, 동시에 여러 키 입력을 발생시켜 게임 내에서 다중 입력이 가능하도록 합니다.

## 주의사항

- **PyAutoGUI failsafe 비활성화**:  
  코드에서는 `pyautogui.FAILSAFE`가 `False`로 설정되어 있으므로, 마우스 커서를 화면 모서리로 이동하여 프로그램을 중단하는 failsafe 기능이 동작하지 않습니다.  
  이로 인해 원치 않는 동작이 발생할 수 있으니 사용 시 주의하시기 바랍니다.

- **카메라 및 조명 환경**:  
  카메라의 해상도, 조명 조건 등에 따라 객체 인식 성능이 달라질 수 있으므로, 필요 시 HSV 범위, hit zone의 좌표, 감지 반경 등을 조정하세요.

- **딜레이 설정**:  
  PyAutoGUI의 기본 딜레이(`pyautogui.PAUSE`)가 0으로 설정되어 있으므로, 너무 빠른 입력이 발생할 수 있습니다. 필요에 따라 딜레이를 추가할 수 있습니다.
